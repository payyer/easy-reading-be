# EasyReading

## Setup

1. Clone the repository.
2. Install dependencies: `npm install`
3. Copy `.env_example` to `.env` and fill in the required values.
4. Run the application: `npm start`

### Environment Variables

- `PORT`: The port number for the server (default: 5000)
- `OPENAI_API_KEY`: Your OpenAI API key for AI features
- `UPLOAD_DIR`: Directory path for file uploads (default: ./uploads)

Make sure to set these in your `.env` file before running the app.
